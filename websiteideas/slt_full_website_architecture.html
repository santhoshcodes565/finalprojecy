Complete User Journey — From Discovery to Trip Completion
1. Discovery & Registration
1
User lands on Home → browses features, sees hero banners & featured tours
2
Clicks "Explore Packages" → Packages page with filters (price, duration, type)
3
Clicks a tour card → TourDetails with itinerary, gallery, seat count, reviews
4
Clicks "Book Now" → redirected to SignIn if not logged in
5
New user? → SignUp → OTPVerify → account created
2. Booking Flow
1
Lands on PackageBooking / CarBooking / DriverBooking depending on service
2
Fills multi-step form: travel date → passengers → pickup details → special requests
3
Reviews booking summary → proceeds to Payment
4
Pays via Razorpay / UPI / Card (advance or full)
5
Arrives at BookingConfirmation → receives email/SMS with booking ID + PDF ticket
3. User Dashboard & Post-Booking
1
MyBookings — view active/past trips, download ticket, request cancellation
2
Notifications — get real-time alerts (departure reminder, driver assigned, payment receipt)
3
After trip completion: prompted to MyReviews — leave rating + feedback
4
MyProfile — manage personal info, saved addresses, linked accounts
Admin Operations — Day-to-Day Management Flow
1. Login & Dashboard Overview
1
Admin logs in via SignIn with admin credentials → role-based redirect to /admin
2
Admin Dashboard shows: today's new bookings count, pending confirmations, revenue snapshot, low-seat alerts
2. Booking Management (Auto-Triggered)
1
User completes a booking → AUTO entry appears in Bookings Manager with status "Pending"
2
Admin reviews booking details → changes status to "Confirmed" / "Cancelled" / "Assigned"
3
On status change → AUTO user gets SMS/email notification via backend webhook
4
For car/driver bookings → assign specific driver or vehicle from the fleet in Cars & Drivers
3. Content & Fleet Management
1
Tours Manager — add new tour package, set seats, pricing tiers, upload photos, set active/inactive
2
Cars & Drivers — add new vehicle, update driver info, toggle availability on/off for any date
3
Reviews Moderator — customer reviews queue up after trips, admin approves before they go live on site
4. Payments & Reporting
1
Payments Tracker — see all transactions, partial pay vs full pay, flag pending balance collections
2
Reports & Analytics — monthly revenue charts, most booked tours, peak season trends, export to CSV
3
User Manager — search any user, view their full booking history, handle complaints, block if needed

Key design rule: Every booking has a status field that both user pages and admin pages read from the same MongoDB document. When admin changes status → user's MyBookings page reflects the update in real-time via polling or WebSocket.
